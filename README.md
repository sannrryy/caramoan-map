# Caramoan barangay map

Interactive coverage map of all **49 barangays** in Caramoan, Camarines Sur. Click a barangay to zoom in. Fill color is land area (darker = larger).

## Open locally

```bash
python -m http.server 8765
```

Then open http://127.0.0.1:8765/

## Data

Barangay polygons: PSA indicative barangay boundaries via GeoRiskPH.
